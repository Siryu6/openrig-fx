# Security policy

## Supported versions

Only the latest release gets security fixes. On OpenRig, the plugin store
offers it as an update.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/Siryu6/openrig-fx/security/advisories/new),
or by email to contact@openrig.eu.

Say which plugin and version are affected, the host, and how to reproduce
it. You will get an answer within a week. Once a fix is released, the
advisory is published and you are credited, unless you prefer not to be.
